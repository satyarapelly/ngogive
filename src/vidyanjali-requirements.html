Vidyanjali Portal Search Integration

Use this panel with the official Vidyanjali school search. Select Telangana plus a district/block below, open the portal, copy the result rows with columns UDISE Code, School Name, Address, State, District, Block, Status, Action, then paste CSV or JSON here. Imported rows merge into the school grid and can be exported as one Excel workbook with a sheet per mandal.

District/mandal options come from Constituency_Mandals_Data.xlsx. The portal may block browser-side scraping because of CORS/CAPTCHA/session rules, so this page supports operator-assisted import and Excel generation from verified results.
